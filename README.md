# ZORO Arabic Voice Studio

توليد تعليق صوتي عربي سحابياً باستخدام **Microsoft Edge Neural TTS**.

## المحرك المعتمد
- المحرك الوحيد: Microsoft Edge TTS عبر مكتبة `edge-tts`
- الصوت الرجالي: `ar-SA-HamedNeural`
- اللغة: العربية
- السرعة والنبرة ومستوى الصوت: افتراضي (دون إبطاء أو تعديل مصطنع)
- الإخراج: `output/narration.mp3`
- لا يحتاج إلى API Key أو حساب أو تنزيل نموذج ذكاء اصطناعي.

## قواعد النص العربي
- اكتب النص في `scripts/story.txt`.
- احتفظ بالتشكيل الموجود في النص كما هو.
- لا يضيف المشروع تشكيلًا تلقائيًا ولا يغيّر الكلمات أو علامات الترقيم.
- لا يضيف فواصل صمت أو وقفات زمنية يدوياً؛ يترك الإلقاء والوقف الطبيعيين للمحرك.
- عند اضطرار النص الطويل إلى التقسيم، يتم التقسيم عند حدود الجمل أو المسافات ثم دمج المقاطع دون إضافة صمت مقصود.

## التشغيل عبر GitHub Actions
1. افتح تبويب Actions.
2. اختر **Generate Arabic Narration**.
3. اضغط **Run workflow**، أو عدّل `scripts/story.txt` وادفع التغيير.
4. بعد نجاح التشغيل افتح Artifact باسم `arabic-narration-mp3` ونزّل ملف MP3.

## استهلاك الإنترنت
التوليد يتم على خوادم GitHub Actions. لا يحتاج هاتفك إلى تنزيل نموذج أو تشغيله؛ لكن خادم GitHub يتصل بخدمة Edge TTS ويرسل النص ويستقبل الصوت. تنزيل ملف MP3 الناتج إلى الهاتف يستهلك بيانات بحجم الملف فقط.

## حدود الخدمة
Edge TTS خدمة متصلة بالإنترنت وليست نموذجاً محلياً مستقلاً. قد تتغير الإتاحة أو حدود الاستخدام لدى Microsoft، ولا يوجد ضمان لاستمرار الخدمة أو توافرها بلا انقطاع.

## الاختبارات
يتحقق Workflow من سلامة Python، وتقسيم النص، وثبات اسم الصوت، ووجود ملف MP3 صالح ومدته قبل رفعه كـ Artifact.
