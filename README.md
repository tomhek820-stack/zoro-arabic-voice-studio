# ZORO Arabic Voice Studio

مشروع مجاني لتوليد تعليق صوتي عربي باستخدام Chatterbox Multilingual V3.

## الإعداد الحالي
- اللغة: العربية (`ar`)
- الأداء المطلوب: راوي رجل عربي، حماسي وجذاب
- شدة التعبير الافتراضية: `0.68`
- `cfg_weight`: `0.35`
- المخرجات: WAV وMP3 192 kbps
- لا توجد مفاتيح API أو أسرار مطلوبة لتنزيل النموذج وتشغيله.
- GitHub Actions يشغّل هذا الإصدار على CPU، وليس GPU.

## تنبيه مهم حول الصوت الرجالي
للحصول على صوت رجل بشكل موثوق، أضف مرجعاً صوتياً تملك حق استخدامه:
`assets/male_reference.wav`

يفضل تسجيل 8–15 ثانية بصوت رجل عربي واضح، دون موسيقى أو ضجيج، بصيغة WAV.
لا ترفع تسجيلاً خاصاً إلى مستودع عام. اجعل المستودع خاصاً إذا كان المرجع الصوتي شخصياً،
أو اترك الملف خارج المستودع واستخدم تشغيلًا محلياً/خاصاً لاحقاً.
إذا لم يوجد المرجع، سيستخدم النموذج صوته الافتراضي ولا يمكن ضمان أن يكون رجاليًا.

## التشغيل على GitHub
1. افتح تبويب Actions في المستودع.
2. اختر Generate Arabic Narration.
3. اضغط Run workflow.
4. انتظر انتهاء المهمة.
5. افتح صفحة التشغيل ثم نزّل Artifact باسم `arabic-narration-wav-mp3`.

يمكن أيضاً تعديل `scripts/story.txt` ثم رفع التغيير؛ عندها يبدأ Workflow تلقائياً.

## حدود التشغيل المجاني
المستودع العام يستفيد من GitHub-hosted standard runners المجانية، لكن هذه الخوادم القياسية CPU فقط.
قد يستغرق توليد نص طويل وقتاً ملحوظاً، ولا يوجد ضمان أن يكون سريعاً.
لا تدّعِ أن GitHub Actions يوفر GPU مجانياً؛ هذا المشروع لا يستخدم GPU على GitHub.

## تشغيل محلي (اختياري)
يتطلب Python 3.11 وFFmpeg وموارد ذاكرة مناسبة:
```bash
python -m pip install chatterbox-tts
python scripts/generate.py
```
